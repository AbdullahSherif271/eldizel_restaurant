El-Dizel Restaurant — E-Commerce Web Application

A responsive e-commerce web application designed for online food ordering, built to provide a smooth and user-friendly ordering experience.

Project Overview
El-Dizel is a modern web platform tailored for restaurant online ordering. It features a dynamic menu, item customization, real-time shopping cart management, and a streamlined checkout workflow designed to optimize user experience and delivery operations.

built with
Angular • TypeScript • HTML5 • SCSS
